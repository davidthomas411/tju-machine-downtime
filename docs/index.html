Usage & Deployment Guide

LINAC Status Dashboard

A clinical operations dashboard for radiation oncology units. This document provides step-by-step usage instructions for staff and administrators, followed by a customization guide for deploying new instances with Supabase.

Institution: Thomas Jefferson University Hospital Version: January 30, 2026 Format: Operational instructions Source: GitHub Repository
Instructions Staff Console Display Wallboard Admin Panel Customization

1. Instructions (Quick Use)

Primary workflow

  1. Open the Staff Console at /dashboard and sign in.
  2. Select the hospital (TJU or LVH) and the site if prompted.
  3. Click the edit icon on a machine card to update status.
  4. Record notes for delays or downtime as needed.
  5. Review analytics in the Statistics tab.
  6. Open the Display Wallboard (/display) for waiting rooms.

Display mode refreshes every 5 seconds and also listens to Supabase Realtime for immediate updates when enabled.

2. Staff Console

Status Updates

Use the edit icon on any machine card to set delays, downtime, or maintenance.

Notes

Attach contextual notes to delays or outages for later reporting.

Statistics

View breakdowns of delay lengths, downtime frequency, and reason summaries.

3. Display Wallboard

The display page is designed for waiting rooms and shared spaces. It is read-only and optimized for large screens.

  • Open /display in a browser and use the Full Screen button.
  • Use the TJU/LVH toggle to switch networks.
  • Weather defaults to Philadelphia for TJU and Allentown for LVH.

4. Admin Panel

Sites

Create hospital sites and assign each to a network (TJU or LVH).

Machines

Add machines, set display order, and mark active vs inactive.

Users

Assign roles and default sites to control what users see first.

5. Customization & New Supabase Setup

Deployment checklist

  1. Create a new Supabase project.
  2. Run the schema scripts in order (see below).
  3. Set environment variables in your hosting platform.
  4. Upload hospital logos to public/brand.
  5. Adjust theme colors in app/globals.css.
  6. Enable Realtime on machines and machine_statuses.
